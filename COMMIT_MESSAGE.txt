feat: Add Online Multiplayer PvP with Realtime and Turn-based Modes

SUMMARY
-------
Implemented complete online multiplayer system for Block Puzzle Game with:
- TCP-based networking layer (NetworkClient, GameNetworkManager)
- Realtime PvP mode (simultaneous play with real-time sync)
- Turn-based mode with chess-clock time management (1/3/5 min per player)
- Node.js server for matchmaking and game session management
- Complete UI integration with menu selection screens
- 8 comprehensive documentation guides

TECHNICAL DETAILS
-----------------
Network Architecture:
  • TCP Socket wrapper with async receive threading (Windows/Linux compatible)
  • Binary protocol with 11 message types (length-prefixed)
  • Server on port 9000 with player matchmaking
  • Callback-based event system for game logic decoupling

Game Modes:
  • Realtime: Both players simultaneous, real-time score updates
  • Turn-based: Chess-clock style with 60/180/300 second time limits
