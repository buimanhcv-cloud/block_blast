🚀 HOW TO PLAY (Quick Start)
================================================================================

STEP 1: Build Game
  $ build_windows.bat
  → Creates BlockPuzzleGame.exe

STEP 2: Start Server (Terminal 1)
  $ node server.js
  → Listens on localhost:9000

STEP 3: Launch Player 1 (Terminal 2)
  $ BlockPuzzleGame.exe
  → Click "Online Đối chiến" (red button)
  → Select "Realtime"
  → Enter: 127.0.0.1
  → Wait for opponent...

STEP 4: Launch Player 2 (Terminal 3)
  $ BlockPuzzleGame.exe
  → Same steps as Player 1
  → When both connected → Game starts! 🎮

🎯 GAME MODES
================================================================================

REALTIME MODE
  • Both players play simultaneously
  • No time limit
  • Scores updated in real-time
  • Win: Highest score OR opponent can't place
  • Best for: Fast-paced action

TURN-BASED MODE (Chess Clock)
  • Players take turns
  • Time limit: 1 minute, 3 minutes, or 5 minutes per player
  • Fair, strategic gameplay
  • Win: Survive longer + higher score combo
  • Best for: Tactical play
